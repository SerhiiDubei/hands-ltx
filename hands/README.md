# Проєкт «Руки»

Референси жестів рук для роботи з LTX-2.5. Стиль: чорно-біла гравюра / stipple, висококонтрастна, срібляста шкіра на суцільному чорному тлі. Усі файли JPEG, довша сторона 1280 px (два квадрати 1254 px).

Джерело: Telegram, збережено 2026-09-12 (`Downloads\Telegram Desktop\photo_1..18_2026-09-12_23-03-50.jpg`, байт-у-байт ті самі файли). У тій самій папці лежать ще `photo_19..26`, які сюди не переносились.

## Структура

| Шлях | Що |
|---|---|
| `ref/` | 18 референсів, назви за жестом |
| `refs.json` | Щільний vision-опис кожного референса + глобальний стиль і prompt anchor |
| `schema.md` | 24 параметри джоба, 10 слотів варіацій, правила промптів |
| `src/variations_*.json` | По 10 дій на жест, 180 промптів-джерел |
| `jobs.json` | Зібрані 180 джобів × 24 параметри |
| `jobs_index.md` | Той самий список у вигляді таблиці для перегляду |
| `jobs_log.jsonl` | Лог сабмітів: prompt_id, статус, час, вихідні файли |
| `tools/build_jobs.py` | Генератор `jobs.json` із валідацією |
| `tools/submit_jobs.py` | Сабмітер у ComfyUI (аплоад, граф, черга, очікування) |
| `PLAN.md` | План дій і статус |
