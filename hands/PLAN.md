# План: руки → LTX-2.5

Мета: 18 референсів жестів стають базою для 180 коротких анімацій (по 10 варіацій на жест), які летять у ComfyUI як параметризовані джоби.

## Статус

| Крок | Що | Стан |
|---|---|---|
| 1 | Референси зібрані у `ref/`, 18 файлів, оригінали з Telegram | готово |
| 2 | Vision-опис кожного референса: композиція, анатомія, світло, семантика, affordances, locks, prompt anchor → `refs.json` | готово |
| 3 | Таксономія 10 слотів варіацій + схема 24 параметрів → `schema.md` | готово |
| 4 | По 10 дій на жест → `src/variations_*.json` (180 промптів) | готово |
| 5 | Генератор `tools/build_jobs.py` → `jobs.json` (180 × 24 параметри) + `jobs_index.md` для перегляду | готово, 0 проблем |
| 6 | Сабмітер `tools/submit_jobs.py`: аплоад референсів, збірка графа, черга, очікування, лог | готово |
| 7 | Смоук-тест на сервері: `H09_V01` (луп + аудіо) і `H09_V08` (вільний кінець, 8 с) | див. `jobs_log.jsonl` |
| 8 | Пакетний запуск 180 джобів | чекає на «го» |
| 9 | QC результатів, відбір переможців, правки промптів, повторні прогони | далі |

## Як запускати

Усе через `py -3`, з будь-якої папки.

```bash
py -3 "E:\Work Stuff\COMFY TEST\hands\tools\build_jobs.py"
```

```bash
py -3 "E:\Work Stuff\COMFY TEST\hands\tools\submit_jobs.py" --list
```

```bash
py -3 "E:\Work Stuff\COMFY TEST\hands\tools\submit_jobs.py" --filter H09_V08 --submit --wait
```

Пакет без очікування, по 20 у чергу (ComfyUI виконує послідовно, лог отримує статус `queued`):

```bash
py -3 "E:\Work Stuff\COMFY TEST\hands\tools\submit_jobs.py" --submit --limit 20
```

Пакет з очікуванням кожного джоба і повним логом статусів (рекомендовано, можна лишити на ніч):

```bash
py -3 "E:\Work Stuff\COMFY TEST\hands\tools\submit_jobs.py" --submit --wait
```

Стан черги на сервері:

```bash
py -3 "E:\Work Stuff\COMFY TEST\hands\tools\submit_jobs.py" --status
```

Уже успішні джоби (по `jobs_log.jsonl`) пропускаються. `--force` перезапускає.

## Оцінка часу пакета

1062 с відео. На твоїх рендерах 10 с при 768×1024 йшло 85–112 с, тобто приблизно 10 с рендеру на 1 с відео. Пакет займе близько 3–4 годин GPU. Вихід у `D:\Comfy-Desktop\ComfyUI-Shared\output\hands\<ref>_<gesture>\`.

## Що варто переглянути перед пакетом

- `jobs_index.md`: усі 180 дій одним списком. Викинути слоти, які не потрібні, можна фільтром, наприклад `--filter V05` запустить лише dolly_in для всіх жестів.
- Слоти V05 і V06 (камера) найризиковіші для стилю: модель може «вигадати» об'єм. Якщо не подобається, виключити.
- Негативний промпт при CFG 1.0 не працює. Якщо треба жорсткіше тримати стиль, підняти `video_cfg` до 1.5–2.0 у `GLOBAL` в `build_jobs.py` і перезібрати.
- Аудіо: порожній `audio` у джерелі дає тихе відео без аудіо-декоду. Зараз тихі лише V06.

## Далі

1. Прогнати пакет, зібрати контактний лист (можна зробити скрипт, що клеїть по 10 варіацій одного жесту в сітку).
2. Для переможців перегнати фінал через двопрохідний шаблон із latent upscaler або з `--force` на іншому сіді.
3. Розширити таксономію під конкретні задачі клієнтів: слоти з відкритим центром під заголовки, лупи для фонів.
